# Week 05 - Wiki 문서화

## 1. 과제 개요
GitHub Wiki에 프로젝트 문서 3개를 작성하고, 문서끼리 서로 링크로 연결했다.

## 2. 제출 문서

| 문서 | 설명 | 링크 |
|---|---|---|
| Getting Started | 프로젝트 시작 및 설치 방법 | [바로가기](https://github.com/pckdou/oss/wiki/Getting-Started) |
| Development Guide | 개발 환경, 브랜치 전략, 협업 규칙 | [바로가기](https://github.com/pckdou/oss/wiki/Development-Guide) |
| Troubleshooting | 자주 발생하는 문제와 해결 방법 | [바로가기](https://github.com/pckdou/oss/wiki/Troubleshooting) |

Wiki 메인: https://github.com/pckdou/oss/wiki

## 3. 문서 간 연결 구조

- Getting Started → Development Guide, Troubleshooting
- Development Guide → Getting Started, Troubleshooting
- Troubleshooting → Getting Started, Development Guide

모든 문서에서 나머지 두 문서로 이동할 수 있도록 `[[문서 제목]]` 문법으로 연결했다.
